# 📖✨ Sobre o Projeto

O **Career Match AI** é uma plataforma desenvolvida para ajudar candidatos a aumentarem suas chances de aprovação em processos seletivos.

💡 Utilizando **Inteligência Artificial**, a aplicação compara o currículo do usuário com a descrição de uma vaga, calcula um percentual de compatibilidade (**Match Score**) e gera automaticamente uma nova versão do currículo em formato **ATS Friendly**, respeitando sempre as informações reais do candidato.

🚀 O projeto foi desenvolvido utilizando **Lovable**, priorizando uma experiência moderna, intuitiva, rápida e responsiva.

---

# 🎯🚀 Objetivos

✅ Facilitar a adaptação do currículo para cada vaga.

✅ Aumentar a compatibilidade com sistemas ATS.

✅ Gerar cartas de apresentação automaticamente.

✅ Tornar o processo de candidatura mais eficiente.

✅ Auxiliar candidatos na preparação para processos seletivos.

# 💡🌟 Visão

O **Career Match AI** tem como missão tornar a criação de currículos personalizados um processo simples, inteligente e acessível.

🤖 A plataforma utiliza Inteligência Artificial para analisar currículos e vagas, gerar versões ATS Friendly e oferecer recomendações que aumentam significativamente as chances de aprovação em processos seletivos.

🚀 Nosso objetivo é conectar talentos às melhores oportunidades, tornando o processo de candidatura mais rápido, eficiente e estratégico para todos.
